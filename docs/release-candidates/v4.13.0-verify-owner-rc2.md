# v4.13.0-verify-owner-rc2

Status: Pixel installed-runtime verified

RC2 keeps the verified RC1 delivery engine and adds a dedicated automation-first CLI/Termux layer.

## Main changes

- New primary `sdd` CLI with stable subcommands for status, targets, target tests, dispatch, delivery status/wait, requeue, logs and diagnostics.
- Machine-readable `--env` and `--json` status/capability/context output.
- `SDD_CHATGPT_CONTEXT_V1`: compact redacted context for ChatGPT/Codex without SSH hosts, remote paths, network addresses or secret content.
- Centralized Termux bridge v2 installs both `sdd` and legacy `dispatch-config`, rejects control-character arguments and avoids `eval`.
- `dispatch-config-v2.sh` preserves interactive/setup compatibility without replacing the hardened bridge.
- Restore/reset paths run through the RC2 config sanitizer and config lint.
- Target setup and migration no longer emit retired `verify*` or `shell_kind` selectors.
- Modernized doctor output with current explicit `shell=` profiles, config lint and a redacted ChatGPT mode.
- CLI version is sourced from installed `module.prop` instead of a hard-coded release string.
- Deterministic Magisk ZIP builder produces a reproducible candidate archive from the pinned source tree.
