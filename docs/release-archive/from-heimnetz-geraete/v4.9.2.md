## Installation / Update auf Pixel

Alle vier Dateien nach `/storage/emulated/0/SYNC/Root/PiDD` legen und dann in Termux ausführen:

```bash
bash -lc '
set -euo pipefail
cd /storage/emulated/0/SYNC/Root/PiDD
bash ./pixel-drop-dispatch-abcd-interactive-v4.9.2.sh
'
```

Empfohlene Reihenfolge im Assistenten:

- A prüfen
- B ausführen
- C ausführen
- D nur ausführen, wenn das bestehende Runtime-Bundle bewusst aktualisiert werden soll

## v4.9.2 Delta gegenüber v4.9.1

- v4.9.1-Dispatcher-Logik bleibt Basis; kein vereinfachter Platzhalter-Service.
- Policy/Marker auf `v492` / `target-aware v4.9.2 final` angehoben.
- Health-Ausgabe erweitert: Main-/Watcher-/Watchdog-PID, Inflight-Größe, Event-Pending, letzter Scan.
- Watchdog startet fehlenden inotify-Watcher neu.
- `scan_locked` setzt Pending-Marker und triggert Follow-up-Scan.
- Stale Scan-Lock Guard mit `DROP_DISPATCH_STALE_LOCK_SECONDS`.
- Neue Runtime-Status-Abfrage: `service.sh --runtime-status`.
- Multi-Pass-Queue bleibt erhalten: `DROP_DISPATCH_SCAN_MAX_PASSES`.
