# SSH Drop Dispatcher v4.10.0-rc1

Initial public release candidate.

## What it is

SSH Drop Dispatcher is an Android/Magisk file-drop dispatcher for routing files to configured SSH targets by filename markers.

## Included

- Magisk module ZIP
- Base64 ZIP copy
- SHA256SUMS
- Installation guide
- How it works documentation
- Configuration guide
- Feature overview
- XDA public RC draft

## Key features

- Filename based routing
- Single and multi-target dispatch
- SSH/SCP upload
- Runtime health checks
- Doctor and config-list commands
- Target registry configuration
- Dispatch state tracking
- Watchdog supported runtime supervision
- No bundled private targets

## Important

This RC does not include private target definitions. Configure your own SSH targets before use.
